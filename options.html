Domínios Git Monitorados

Adicione hosts públicos ou internos (ex: gitlab.corp.local, git.interno.com). O tipo define como o endereço é lido; para trocar o tipo de um host, adicione-o de novo.

Agrupamentos

Junte domínios e repositórios sob um título pelo trecho do endereço (ex: openshift, .prevnet). Basta uma URL casar para o domínio ou repositório inteiro entrar no agrupamento; se casar com mais de um, vale o primeiro da lista (use ↑ e ↓ para mudar a ordem e ✎ para editar).

Itens Ocultos

Repositórios e domínios ocultos pelo × no canto do card não aparecem no painel, nem na busca. Use Mostrar para que um item volte a aparecer.
